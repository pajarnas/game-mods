## Local testing

Copy a mod folder into the staging area, then enable it when starting a new game:

```
C:\Program Files (x86)\Steam\userdata\<Steam ID>\3493540\local\staging_area\
```

Run the validator in Mod Hub > My Mods before uploading. Bump `revision` in `mod.json` before each upload.
