## 本地测试

把 mod 文件夹复制到 staging area，新建游戏时勾选启用：

```
C:\Program Files (x86)\Steam\userdata\<Steam ID>\3493540\local\staging_area\
```

上传前，在 Mod Hub > My Mods 里运行验证。每次上传前把 `mod.json` 里的 `revision` 加 1。
